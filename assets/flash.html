Send by Flash

Your library, straight off the screen.

The iPhone shows a fast stream of QR codes and this computer's camera reads them. No Wi-Fi, no internet.

  1. On your iPhoneOpen Zone, then Settings > Computers > your computer > Send by Flash.
  2. Hold it up to the cameraLet the code fill the square, about a hand's width away, with the screen brightness up.
  3. Watch it assembleEvery tile is a piece of your library. Any code helps, in any order, so missed ones do not matter.

The iPhone has to be paired with this computer once, because the codes are encrypted with a key both sides got at pairing. Pairing needs no network either: choose Pair a phone in your library and scan the code with the iPhone (or run zone pair in a terminal). If you put the phone down early, nothing is stored and you can start again.
